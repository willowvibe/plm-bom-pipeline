What it proves

Multi-level BOMs

A recursive explosion with effectivity filtering, accumulated quantities and a cycle guard, rolled up to product cost and weight.

Change impact

Every ECR, ECO and ECN is mapped to the products that reach its affected part. Shared raw materials make impact cross product boundaries.

Quality that bites

Seven seeded PLM defects, one singular test each. The harness proves exactly one failure per defect and 188 built-in checks green on every dataset.

03

Reproduce it

Requires Python 3.11+ and make. One install, then the quickstart generates the data, builds the marts, runs the tests and writes the report.

python3 -m venv .venv-dbt
. .venv-dbt/bin/activate
pip install -r requirements-dev.txt

make demo
make verify-defects

The full source, data model and defect details are in the repository.
